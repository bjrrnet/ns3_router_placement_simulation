# ns3_router_placement_simulation
A simple simulation based on a sketch of a floorplan, run to simulate which position of the router is more optimal.

# Use of AI assistance
The AI assistant Claude (Anthropic) was used as a helping tool in this project. It helped with: explaining ns-3 and the example program; writing the Python helper ns3_pairs.py that counts walls and chimney contacts for each router–client pair; plotting the results; searching for literature; spellchecking parts of the report text. The ns-3 program DAT400projekt.cc was written and run by me, as a modified copy of the ns-3 example wifi-spectrum-per-example.cc. The choice of layout, router and client positions, assumptions and conclusions are mine.
